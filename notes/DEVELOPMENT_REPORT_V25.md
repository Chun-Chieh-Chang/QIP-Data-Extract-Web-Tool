## 功能需求回顧

### 原始需求

1. **優化選取流程**: 自動區分 ID 與數據範圍，減少手動繁瑣操作。
2. **智慧模式**: 當選取多行範圍時，自動將第 1 行設為 ID，其餘設為數據範圍。
3. **UI 簡化**: 移除冗餘按鈕，並重新規劃按鈕配置。

### 實現方案

1. **智慧拆分邏輯 (`app.js`)**: 在 `confirmSelection` 中加入偵測，若選取多行，則根據 Pt 1 所在行自動拆分。
2. **按鈕位置重規劃 (`index.html`)**: 將按鈕從輸入框旁移至「模穴組」標頭，並強化為「智慧選取」操作入口。
3. **焦點連動**: 更新輸入框聚焦監聽，確保點選欄位時能正確觸發標頭的選取模式。

## 修改內容詳述

### 1. 代碼修改 (1 個文件)

#### `js/ui/app.js`

- **`confirmSelection`**:
  - 新增 `isMultiRow` 判斷邏輯。
  - 根據 `selectionStart.row` (Pt 1) 決定 ID 行位置。
  - 自動計算並更新對應的 `ID Input` 與 `Data Range Input`。
- **Focus Event Listener**:
  - 修改範圍輸入框的聚焦監聽器，使用 `closest('.cavity-group')` 向上尋找容器，確保能對應到標頭內的新按鈕。

### 2. UI 修改 (1 個文件)

#### `index.html`

- **標頭配置**: 為 6 個模穴組新增標頭按鈕區，將 `select-range-btn` 移入。
- **標籤更新**: 更新 ID 區域標籤為「ID 區域 (智慧模式：連帶選取數據區)」。
- **樣式優化**: 使用 Tailwind CSS 調整按鈕為藥丸形狀，並加入「智慧選取」文字提示。
- **欄位清理**: 移除數據區域右側的重複按鈕，騰出輸入空間。
