系統技術操作手冊

QIP AUTO EXTRACTOR PROFESSIONAL v2.4

01

analytics 核心作業流程詳解

1
全自動批量導入 (Batch Import)

系統支援「多檔案平行讀取」。您可以直接將整個資料夾的 QIP 報表（.xlsx / .xlsm）選取並拖入。
技術提示： 系統會將所有檔案暫存在本地記憶體，不會產生任何雲端流量。

2
座標映射邏輯 (Coordinate Mapping)

這是系統精準提取的關鍵。您需要為每個模穴組定義兩大區塊：

  • ID 區域： 通常是指檢驗項目的「名稱」或「標籤」所在範圍（例如：A3:L3）。
  • 數據區域： 則是對應上述項目的「實測數值」所在範圍（例如：A4:L4）。
重要： ID 與 數據區域的欄位總數必須完全一致。

3
視覺化範圍選取器 (Visual Picker)

點擊輸入框旁邊的 biotech 圖標可啟動選取器：

  1. 首先點擊目標範圍的 起點儲存格。
  2. 接著點擊目標範圍的 終點儲存格，系統會自動高亮該區域。
  3. 點擊下方導航條的「確認選取」完成綁定。
02

settings_applications 智能配置與保管庫

storage
配置檔案管理

您可以儲存各種不同產品的映射範本。

儲存： 輸入範本名稱並點擊 save_alt。
讀取： 點擊 folder_zip 即可從庫中快速加載，並支援關鍵字搜尋。

auto_fix_high
批量同步邏輯

如果您導入了 10 個檔案，系統會自動在每個檔案中尋找與您當前配置相同名稱的工作表進行數據提取。

gpp_maybe

warning 疑難排解與安全須知

無法點擊啟動按鈕？ 確保 SKU ID 已填寫，且「模穴 01-08」的範圍已正確定義（這是核心必填項）。

數據提取為空值？ 請檢查 Excel 工作表是否受保護，或是數據區域是否包含非數值字元。

資料安全聲明： 本系統採用邊緣計算架構。任何導入或提取的資料絕對不會離開您的電腦環境，請放心使用。

03

terminal 進階技術參數

關於「工作表同步」邏輯

系統在處理多檔案時，會優先比對每個工作簿中的工作表名稱。

匹配機制： 如果您的範本選取了名為「Report_A」的工作表，系統在批量處理其他檔案時，也會自動搜尋名為「Report_A」的分頁進行提取。若找不到同名分頁，該檔案將會被跳過並記錄在報錯日誌中。

ID 與數據配對準則

為了確保輸出的 CSV/Excel 格式整齊，請遵循以下規則：

  • 水平映射： 若 ID 區域為橫向（如 A1:E1），數據區也必須為橫向且欄數相同。
  • 垂直映射： 若 ID 區域為縱向（如 A1:A10），目前引擎會自動將其轉置為水平格式輸出。
  • 空值處理： 若數據區域包含空儲存格，系統會自動填入「N/A」。
